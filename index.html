A semantic component library for generating Microsoft Word documents from JavaScript. Build resumes, reports, letters, contracts — any structured document — with composable functions.

Why DocLang

Documents as code

Stop fighting with formatting. Describe the structure, get the document.

📝

Semantic API

Components read like document sections: Header(), Experience(), Summary(). No layout code needed.

🎨

Built-in Design System

Professional defaults out of the box. Arial typography, consistent spacing, proper hierarchy. Override anything with themes.

📄

Real Word Documents

Generates standard .docx files. No PDF hacks, no HTML conversions. Opens in Word, Google Docs, LibreOffice.

⚡

One-Line Export

exportFile() saves your document as DOCX or PDF with a single call. No boilerplate required.

🧩

Composable Components

Header, Experience, Education, Skills, Projects, Certifications, Languages, Awards, References — mix and match freely.

🎯

Themeable

Override any style token with createStyles(). Change fonts, colors, spacing — the API stays the same.

Quick Start

From zero to document
in 30 seconds

Import the components you need, describe your document structure, and export. That's it.

Install

npm install doclang docx

Export

await exportFile(document, { fileName: "output" })
generate.ts 
import {
  Resume, Header, Name, Designation,
  Contact, Summary, Experience, ExperienceItem,
  Skills, Skill, Education, EducationItem,
  exportFile,
} from "doclang";

const resume = Resume(
  Header(
    Name("Jane Smith"),
    Designation("Software Engineer"),
    Contact({
      email: "jane@example.com",
      phone: "+1 555 123 4567",
    })
  ),
  Summary(
    "Full-stack engineer with 8+ years building " +
    "scalable distributed systems."
  ),
  Experience(
    ExperienceItem({
      company: "Tech Corp",
      designation: "Senior Engineer",
      duration: "2021 — Present",
      points: [
        "Led microservices migration",
        "Reduced deploy time by 70%",
      ],
    })
  ),
  Skills(
    Skill("TypeScript"),
    Skill("React"),
    Skill("Node.js")
  )
);

await exportFile(resume, {
  fileName: "jane_smith",
  pdf: true,
});

Components

Build any document

Semantic components that map to document sections. Each handles its own typography, spacing, and layout. Compose them freely.

Resume() Root document assembler
Header() Title, contact, photo
Summary() Introductory text block
Experience() Entries with roles and details
Education() Degrees and institutions
Skills() Skills or tag lists
Projects() Project entries with details
Certifications() Certifications and issuers
Languages() Languages and proficiency
Awards() Awards and recognitions
References() Contact references
exportFile() Save as DOCX or PDF

CDN

Use without npm

Import directly from a CDN in any JavaScript project. No build step required.

index.js 
import {
  Resume, Header, Name,
  Summary, exportFile,
} from "https://esm.sh/doclang";

import { Packer } from "https://esm.sh/docx";

const resume = Resume(
  Header(Name("Your Name")),
  Summary("Your summary here.")
);

const buffer = await Packer.toBuffer(resume);
